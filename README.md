# Data Structures and Algorithms Notes

This repository documents my learning of data structures and algorithms, with a focus on their applications in data engineering and data analysis.

## 📚 What’s inside

* Core data structures (arrays, hash maps, trees, graphs)
* Algorithm patterns (sorting, searching, sliding window, etc.)
* SQL problem-solving and query patterns
* Real-world data use cases (e.g., deduplication, top-k queries, indexing)
* Problem-solving notes and learnings

## 🎯 Purpose

The goal of this repository is to:

* Build a strong foundation in data structures and algorithms
* Understand how these concepts are applied in real data workflows
* Improve problem-solving skills for data-related tasks
* Develop a pattern-based approach to solving problems

## 🛠️ Tech Stack

* SQL
